# Project-Overdrive

2026-08-28 - 2026-08-30
OZ 게임잼 출품작품입니다.

팀 구성 : 2명

담당 업무
- 오브젝트 풀링
- 몬스터
- 웨이브 시스템
- 에셋, SFX, BGM 탐색 및 적용

## 주제 : 초격차
플레이어와 몬스터, 그리고 게임 초반과 후반 캐릭터 사이에 존재하는 '넘볼 수 없는 성장의 격차'로 해석했습니다.
수많은 적을 압도적인 화력으로 쓸어버리며 한계를 뛰어넘어 완전히 다른 차원의 힘을 손에 넣는 초격차의 쾌감을 구현했습니다.

## 기술 스택
- Unity 6
- C#

## 주요 구현

### 1. 몬스터 데이터 관리 및 오브젝트 풀링
오브젝트 풀링을 통한 최적화와 Scriptable Object 기반 몬스터 데이터 관리 시스템을 구현했습니다.

### 2. 웨이브 시스템
웨이브 데이터를 Scriptable Object로 만들어 웨이브 별 지속 시간, 스폰 간격, 스폰할 몬스터 종류, 스폰 방식 등을 설정하여 관리할 수 있도록 시스템을 구현했습니다.
